# Dados originais

Esta pasta preserva os arquivos recebidos para o case sem alterações de
conteúdo ou de codificação. O arquivo `tribunal.csv`, por exemplo, permanece
em ISO-8859-1 exatamente como foi entregue.

Para conferir a integridade a partir da raiz do repositório:

```bash
shasum -a 256 -c data/raw/SHA256SUMS
```
